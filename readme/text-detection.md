# Text Forensics — Architecture

> How the AI-generated-text detector works: preprocessing, the four scoring
> branches, score fusion, training, and the inference API — end to end.

## 1. Overview

The text pipeline decides whether a piece of text was written by a **human**
or generated by an **AI language model** (ChatGPT, Llama, etc.). It fuses
*four independent detectors* into one calibrated probability:

| # | Branch            | Type       | Needs training? | Needs a reference LM (GPT-2)? |
|---|-------------------|------------|-----------------|-------------------------------|
| 1 | **Supervised**    | fine-tuned RoBERTa classifier | Yes (this repo) | No |
| 2 | **DetectGPT**     | curvature under a reference LM | No | Yes |
| 3 | **GLTR**          | perplexity + token-rank histogram | No | Yes |
| 4 | **Stylometry**    | lexical/rhythm statistics | No | No |

The final score is `p_ai = 0.6 · supervised + 0.4 · zero_shot`, where
`zero_shot` fuses branches 2–4 with a hand-set logistic. If the supervised
checkpoint is missing, only the zero-shot signal is used (still works
out of the box).

## 3. The branches — what each one measures

### 3.1 Supervised branch (`supervised_score`, detector.py:176)

A sequence classifier (`distilroberta-base` in the shipped checkpoint) fine-tuned
on human/AI pairs (HC3). Returns `P(ai_generated)` from softmax over logits.

- **Read as:** 1.0 → the model is sure the text matches the distribution of
  AI texts it was trained on.
- **Strong point:** domain-tuned accuracy (val AUC 1.0000 on the HC3 split).
- **Weak point:** in-distribution only — degrades on other LLMs, styles, or
  paraphrased text it never saw.

### 3.2 DetectGPT curvature (`detectgpt_curvature`, detector.py:131)

Theorizes that AI text sits on a **sharp local maximum** of a reference LM's
log-likelihood surface, while human text sits on a flat region.

1. Score the original text's mean log-probability under GPT-2.
2. Make `n_perturb = 8` perturbed copies (random word deletion/swap, or the
   paper-faithful T5 mask-fill if `perturbation="t5"`).
3. Score each variant; compute the mean likelihood **drop** normalized by the
   perturbation standard deviation.

- **Read as:** `(orig − mean_perturbed) / (std + ε)`. Positive & large ⇒ AI.
- **Reference LM:** GPT-2 (`REFERENCE_LM = "gpt2"`, detector.py:28), downloaded
  to the Hugging Face cache on first use (~550 MB).

### 3.3 GLTR statistics (`gltr_features`, detector.py:161)

A "predict-the-next-token" probe. GPT-2 predicts each token; we measure how
*typical* the actual token was:

- **Perplexity** `exp(−mean log-prob)` — low ⇒ GPT-2 finds the text highly
  predictable ⇒ machine-like. High ⇒ surprises the LM ⇒ human-like.
- **`frac_rank_top10` / `frac_rank_top100`** — fraction of tokens that landed
  in GPT-2's top-10 / top-100 choices. AI text concentrates in the top ranks.
- **`frac_rank_1000plus`** — tokens GPT-2 ranked beyond 1000 (rare/surprising).
- **`logprob_std`** — per-token log-prob variance (burstiness of likelihood).

### 3.4 Stylometry (`stylometric_features`, stylometry.py)

Lexical statistics that survive paraphrase attacks:

- **Burstiness** `(σ − μ)/(σ + μ)` over sentence lengths — AI writing has a
  regular rhythm (−1 = perfectly uniform); human writing is bursty.
- Average sentence / word length, their variance.
- **Type–token ratio** and **hapax (once-only word) ratio** — vocabulary richness.
- Frequency of the top-20 **function words** ("the", "and", "of", …) and of
  punctuation marks — stable stylistic fingerprints.

## 4. Zero-shot fusion (`_zero_shot_p_ai`, detector.py:186)

Training-free signals are mapped to a probability with a hand-set logistic:

```
z  = 6.0·(frac_rank_top10 − 0.62)          # AI ~0.75+, human ~0.45
   + 1.5·(2.2 − log10(perplexity)·2.0)
   + 1.2·(1.6 − logprob_std)
   + 1.0·tanh(curvature − 0.4)             # if curvature available
   + 1.0·(−0.35 − burstiness)
p_ai = 1 / (1 + exp(−z))
```

Thresholds follow published GLTR/DetectGPT observations. The final verdict:

```
p_ai     = 0.6·supervised + 0.4·zero_shot   (if a checkpoint was loaded)
label    = "ai_generated" if p_ai ≥ 0.5 else "human"
confidence = p_ai          for AI
            = 1 − p_ai     for human
```

## 5. Span localization (`_localize_spans`, detector.py:237)

When the text has ≥ 4 sentences, a window of 3 sentences slides across the
document; each window is re-scored (GLTR + stylometry + supervised blend) and
returned as `span_scores`, flagging *which part* of the document looks AI.

## 6. Data & training

Data format (converted by `scripts/download_datasets.py`, or synthetic):

```
data/text/train/human.jsonl      one {"text": ...} per line
data/text/train/ai.jsonl
data/text/val/human.jsonl
data/text/val/ai.jsonl
```

Training (`mmforensics/training/train_text.py`):

```
python -m mmforensics.training.train_text --data data/text --epochs 4
# smoke test without downloading any data:
python -m mmforensics.training.train_text --smoke
```

- Model: `roberta-base` (default) / `microsoft/deberta-v3-base` /
  `distilroberta-base` — 2-class `AutoModelForSequenceClassification`.
- Augmentation (`augment_text`, datasets.py:166): synonym substitution,
  sentence shuffle, word dropout — paraphrase robustness.
- Optimizer: AdamW + OneCycleLR, grad-clip 1.0; best-val-AUC checkpoint saved
  to `checkpoints/text/` (Hugging Face format).
- Metrics: `summarize()` in `mmforensics/training/metrics.py` (AUC, F1, EER).

## 9. Notes & trade-offs

- **GPT-2 dependency:** branches 2–3 download `gpt2` (~550 MB) to the Hugging
  Face cache on first use and load it lazily (`_load_lm`, detector.py:55).
  `scripts/test_text.py` avoids it entirely by calling `supervised_score()`
  only.
- **Short / degenerate text:** `< 10 words` returns `curvature = null`; a very
  short document yields a usable GLTR-only score or `label: "unknown"`.
- **Hand-tuned, not learned:** `_zero_shot_p_ai` thresholds are heuristic.
- **To drop GPT-2 while keeping zero-shot:** train a small causal LM on your
  data and point `REFERENCE_LM` at its local path.
